# Video Plan: "Journey Inside the Atom" (Chapter 8) — Exam-Focused Cut

**Source:** NCERT *Curiosity* — Grade 9 Science, Chapter 8
**Format:** 6 crisp concept videos, 2.5–4 min each (~19 min total). No narrative framing, no cliffhangers, no scientist backstory beyond the one fact that's actually examinable (who discovered what, in which year). Every video is definition → diagram → formula → solved example → rapid recap, because that's the sequence students need when revising.
**Design rule:** every definition below is written in the exact wording examiners expect back. Every numerical is either lifted from or modeled directly on the chapter's own "Pause and Ponder" / "Revise, Reflect, Refine" questions, since those are the highest-probability exam sources.

---

## Episode 1 — Atomic Models: Thomson → Rutherford → Bohr
**Runtime:** ~4 min | **Exam weight:** Highest. The gold foil experiment (observations → conclusions), model comparisons, and "why did X model fail" are near-guaranteed as either a 3–5 mark question or an assertion-reason.

| Screen | Content |
|---|---|
| Diagram 1 | Thomson's model: sphere of positive charge with electrons embedded in it ("plum pudding"). |
| Definition | *Thomson's model:* atom is a positively charged sphere with electrons distributed throughout it. |
| Diagram 2 | Gold foil experiment setup: α-particle beam → thin gold foil → circular detector screen. Mark the three outcomes with arrows: (a) most pass straight through, (b) some deflect at large angles, (c) very few bounce straight back. |
| Observations → Conclusions table | **Say this, in this exact pairing — this is the most commonly asked part of the whole chapter:**<br>• Most α-particles pass undeflected → atom is mostly empty space.<br>• Few deflect at large angles → a small, dense, positively charged region exists.<br>• Very few bounce back → that region (nucleus) holds most of the mass and all the positive charge, concentrated in a tiny volume. |
| Definition | *Rutherford's model:* atom has a small, dense, positively charged nucleus at the centre; electrons revolve around it like planets around the Sun (planetary model). |
| Scale fact | Atom diameter ≈ 10⁻¹⁰ m; nucleus diameter ≈ 10⁻¹⁵ m → nucleus is about 10⁵ (one lakh) times smaller than the atom. |
| Limitation (write this as a standalone examinable line) | Rutherford's model could not explain atomic stability — an orbiting (accelerating) electron should continuously lose energy and spiral into the nucleus, but atoms are observed to be stable. |
| Diagram 3 | Bohr's shells K, L, M, N around a nucleus, concentric circles, labelled n = 1, 2, 3, 4. |
| Definition | *Bohr's model:* electrons move only in fixed circular orbits (shells/energy levels) without losing energy; an electron changes shells only by absorbing or releasing a fixed amount of energy equal to the difference between the two levels. |
| One-line discoverer facts (MCQ fodder) | Thomson – electron, 1897. Rutherford – nucleus/gold foil experiment, 1911 (with Geiger & Marsden). Bohr – energy-level model, 1913. |
| Comparison table (hold this frame the longest — students screenshot this) | **Model → Key idea → Failed because**<br>Thomson → positive sphere + embedded electrons → couldn't explain gold foil scattering<br>Rutherford → dense nucleus + orbiting electrons → couldn't explain atomic stability<br>Bohr → fixed energy-level orbits → superseded by the quantum mechanical model (higher grades) |
| Recap (rapid-fire, on-screen bullets only, no VO) | ✅ Gold foil = 3 observations → 3 conclusions (memorise the pairing)<br>✅ Rutherford's failure = the "why don't electrons fall into the nucleus" question<br>✅ Bohr fixes it with fixed energy levels |

**Likely exam Qs to flash at the end:** "Which observation of the gold foil experiment led to which conclusion?" · "Why did Rutherford's model fail while Bohr's succeeded?" · Assertion–Reason on nucleus mass/charge concentration.

## Episode 2 — Subatomic Particles
**Runtime:** ~2.5 min | **Exam weight:** Medium-high — usually a direct table-recall or fill-in-the-blank, sometimes folded into a numerical.

| Screen | Content |
|---|---|
| Table (build it live, one row at a time) | **Particle → Symbol → Relative charge → Found where**<br>Electron → e⁻ → –1 → revolving around nucleus<br>Proton → p⁺ → +1 → nucleus<br>Neutron → n⁰ → 0 → nucleus (absent only in ordinary hydrogen, ¹₁H) |
| One-line discoverer facts | Electron – J.J. Thomson (1897, cathode ray tube). Proton – Rutherford. Neutron – James Chadwick (1932). |
| Key rule (write as its own card) | For a neutral atom: number of protons = number of electrons. |
| Why neutrons exist (1-line, often asked as HOTS) | Neutrons add mass without adding charge, and reduce proton–proton repulsion in the nucleus, helped by the nuclear force — this is why heavier atoms need proportionally more neutrons than protons (e.g., iron: 26p/30n; uranium: 92p/146n). |
| Recap | ✅ e⁻ = –1, p⁺ = +1, n⁰ = 0 — memorise cold<br>✅ protons = electrons in a neutral atom<br>✅ mass of atom ≈ mass of (protons + neutrons); electron mass is ignored |

**Likely exam Qs:** "Complete the table of subatomic particles." · "Name the scientist and year for each discovery." · Assertion–Reason: "number of electrons = number of protons" as the Reason.

## Episode 3 — Atomic Number, Mass Number & Notation
**Runtime:** ~3 min | **Exam weight:** Very high — this is where most numericals come from (fill-the-table questions like Table 8.5 in the chapter are a recurring format).

| Screen | Content |
|---|---|
| Definitions (exact wording) | *Atomic number (Z)* = number of protons in the nucleus of an atom.<br>*Mass number (A)* = total number of protons + neutrons (nucleons) in the nucleus. |
| Formula box | **A = Z + number of neutrons** → number of neutrons = A − Z |
| Notation diagram | Build ᴬ_Z(Symbol) on screen stroke by stroke, e.g. ¹²₆C — mass number top-left, atomic number bottom-left. |
| Solved example 1 | Atom has atomic number 26, mass number 56.<br>Protons = 26, Electrons = 26 (neutral atom), Neutrons = 56 − 26 = **30**. |
| Solved example 2 | Nucleus has 20 protons, mass number 41.<br>Neutrons = 41 − 20 = **21**. |
| Solved example 3 | Atomic number 17, neutrons 18.<br>Mass number = 17 + 18 = **35**. |
| Recap | ✅ Z = protons = electrons (neutral atom)<br>✅ A = protons + neutrons<br>✅ neutrons = A − Z — this single formula solves ~80% of numericals in this chapter |

**Likely exam Qs:** direct "find protons/neutrons/electrons given Z and A" (appears almost every year in some form) · complete-the-table questions · "write in ᴬ_Z(symbol) notation."

## Episode 4 — Electronic Configuration
**Runtime:** ~3.5 min | **Exam weight:** High — the 2n² rule and configuration-writing are near-certain to appear, often combined with valency in the same question.

| Screen | Content |
|---|---|
| Rules (state as a numbered, quotable list — this is exactly how it should be reproduced in an answer) | 1. Maximum electrons in a shell = 2n² (n = shell number).<br>2. Maximum electrons in the outermost shell = 8 (except when it's the only shell, which caps at 2).<br>3. Shells fill in order, innermost first: K, then L, then M, then N — a shell fills completely before the next one starts. |
| Formula box | K (n=1): 2×1² = 2 · L (n=2): 2×2² = 8 · M (n=3): 2×3² = 18 |
| Diagram | Shells filling for the first 18 elements — show 4–5 worked ones on screen (H, He, Ne, Na, Ar), not all 18; direct viewers to the textbook's Table 8.4 for the full list. |
| Solved example | Sodium, Z = 11 → configuration **2, 8, 1** (K=2, L=8, M=1). |
| Solved example (numericals style) | ¹²₆C → outermost shell electrons = 4. ¹⁹₉F → outermost shell electrons = 7. |
| Recap | ✅ 2n² gives max capacity per shell<br>✅ Outer shell caps at 8<br>✅ Fill K → L → M → N, never skip |

**Likely exam Qs:** "Write electronic configuration for atomic number __." · "How many electrons in the outermost shell of [given notation]?" · Numericals combining Z/A with configuration (e.g., magnesium, Z=12, A=24 — write config).

## Episode 5 — Valency
**Runtime:** ~3 min | **Exam weight:** Medium-high, frequently paired with electronic configuration in the same question.

| Screen | Content |
|---|---|
| Definitions | *Valence shell* = outermost shell of an atom. *Valence electrons* = electrons present in it. *Octet* = 8 electrons in the valence shell (stable, unreactive configuration; 2 for helium). *Valency* = number of electrons gained, lost, or shared by an atom to complete its octet. |
| Rule box (state plainly, this is the exact logic examiners test) | Valence electrons < 4 → atom **loses** electrons → valency = number of valence electrons.<br>Valence electrons > 4 → atom **gains** electrons → valency = 8 − (number of valence electrons).<br>Valence electrons = 4 → atom **shares** electrons → valency = 4. |
| Solved example 1 | Sodium: configuration 2,8,1 → 1 valence electron → loses 1 → **valency 1**. |
| Solved example 2 | Oxygen: configuration 2,6 → 6 valence electrons → gains 2 → **valency 2**. |
| Solved example 3 | Carbon: configuration 2,4 → 4 valence electrons → shares 4 → **valency 4**. |
| Recap | ✅ Valency = electrons lost/gained/shared to reach 8 (or 2)<br>✅ <4 lose, >4 gain, =4 share<br>✅ Full octet already = stable, won't react further |

**Likely exam Qs:** "Find the valency of an element given its electronic configuration." · Combined Z/A/configuration/valency questions (this exact combo appears in the chapter's own Q9 and Q14).

## Episode 6 — Isotopes, Isobars & Average Atomic Mass
**Runtime:** ~4 min | **Exam weight:** High — the weighted-average-atomic-mass numerical is one of the most reliably repeated question types from this chapter.

| Screen | Content |
|---|---|
| Definitions | *Isotopes* = atoms of the same element (same atomic number) having different mass numbers (different number of neutrons). *Isobars* = atoms of different elements having the same mass number but different atomic numbers. |
| Diagram | Hydrogen's 3 isotopes side by side: protium (1p, 0n), deuterium (1p, 1n), tritium (1p, 2n) — all have 1 electron. |
| Key line (commonly asked as "why") | Isotopes have identical chemical properties (same number of valence electrons) but different physical properties (e.g., boiling/melting point). |
| Applications (one line each — MCQ fodder) | ²³⁵₉₂U → nuclear fuel. ⁶⁰₂₇Co → cancer radiotherapy. ¹³¹₅₃I → thyroid treatment. ¹⁴₆C → carbon dating (age of fossils). |
| Formula box | **Weighted average atomic mass = Σ (isotope mass × % abundance) / 100** |
| Solved example (do this one fully, on-screen, step by step — highest-yield numerical in the chapter) | Chlorine: ³⁵Cl (75%, mass 35 u) and ³⁷Cl (25%, mass 37 u).<br>Average = (35×75 + 37×25) / 100 = (2625 + 925) / 100 = 3550/100 = **35.5 u** |
| Isobars example | Calcium (Z=20), Potassium (Z=19), Argon (Z=18) — all have mass number 40, different atomic numbers → isobars. |
| Recap | ✅ Isotopes: same Z, different A, same chemistry<br>✅ Isobars: same A, different Z, different elements entirely<br>✅ Weighted average formula — practice with different % splits, this is a guaranteed numerical |

**Likely exam Qs:** "Calculate average atomic mass given two isotopes and their % abundance" (near-certain) · "Distinguish between isotopes and isobars" · match-the-isotope-to-its-use.

## One-page revision card (optional final 90-second recap video)

- Gold foil: 3 observations → 3 conclusions (memorise the pairing, Episode 1).
- e⁻ = –1, p⁺ = +1, n⁰ = 0.
- Z = protons = electrons; A = protons + neutrons; neutrons = A − Z.
- Shell capacity = 2n²; outer shell caps at 8; fill K→L→M→N.
- Valency: <4 valence e⁻ lose, >4 gain, =4 share.
- Isotopes = same Z, different A. Isobars = same A, different Z.
- Weighted average atomic mass = Σ(mass × %abundance)/100.

This card is the single frame most worth freezing for a last-minute revision screenshot — consider ending the whole series on it.
